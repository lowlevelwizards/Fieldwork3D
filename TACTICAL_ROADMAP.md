# Fieldwork 3D — Tactical Operations Roadmap

Current build: **0.0.9 — First Contact** (Oct 2026)

This is the approved sequence, not a declaration that all ten milestones are complete.

| Build | Status | Milestone | Concrete next gate |
|---|---|---|---|
| 0.0.9 | PLAYABLE VERTICAL SLICE | First Contact | Validate gun feel, targeting, mobile controls and patrol collision on iPhone |
| 0.0.10 | FOUNDATION ONLY | Cover Is Survival | Deliberate crouch, leaning and directional exposure rather than line blocking alone |
| 0.0.11 | FOUNDATION ONLY | They're Out There | Searching and hearing exist; add asymmetric detection, uncertainty and patrol schedules |
| 0.0.12 | FOUNDATION ONLY | Watch My Back | Follow/hold/cover/withdraw exist; add coordinated move-and-cover / overwatch |
| 0.0.13 | FOUNDATION ONLY | Every Bullet Matters | Finite ammo, reload, suppression and flinch exist; add physical armor, regions and handling |
| 0.0.14 | INITIAL MECHANIC | Nobody Gets Left Behind | Downed animation and proximity aid exist; add drag/carry, treatment, meaningful recovery |
| 0.0.15 | FOUNDATION ONLY | The Job Comes First | Maintenance and firefights share a simulation; add escort, recovery and extraction missions |
| 0.0.16 | FOUNDATION ONLY | Contact! Break Contact! | Patrol investigates, suppresses, uses cover and retreats when hurt; add team-level flanks and plans |
| 0.0.17 | NOT STARTED | A World That Pushes Back | Persistent factions, meaningful territory, reinforcements and communications consequences |
| 0.0.18 | NOT STARTED | Get In. Do the Work. Get Everyone Back. | Multi-site task day, equipment preparation, stealth/avoidance choices, extraction and debrief |

Non-negotiables:

1. Maintain one world: no combat instance that discards machine state, mission state or operator obligations.
2. Actor bodies, reach, collisions, cover, movement, ammunition and recoveries should matter physically.
3. Low-poly miniature aesthetic, grounded chunky silhouettes and restrained mobile UI.
4. Keep most behaviors testable headlessly without rendering; never silently teleport or fake a shot through cover.
5. Complete and verify a focused vertical slice before widening the scope to larger systems.
