# D3.30G — recorded doorway navigation without hidden-state disclosure

When an operator has an interrupted-entry snapshot with a witnessed physical door ID, the selected operator's floor plan and projected planning view draw a single subtle marker at that door. This is historical location evidence, not a live lock/open/jam indicator. Replay mode excludes this marker; resolving the incident through an explicit retry removes it. Opening, kicking and equipped tools remain delegated to the normal physical door palette and motor authority—no shortcut, auto-unlock, or second interaction system.

The marker is screen-space overlay art, not another route search or 3D mesh. Focused tests confirm no marker for unwitnessed doors, independence from subsequent hidden door state, and removal with the preserved snapshot.
