## W7.0 audit
Generated floors are opaque Standard box slabs (inset 0 for programLocked, 2 otherwise) plus one transparent Basic plane per room when condition>0. The plane's mapPlanePixelUV repeats world UVs, unlike the normalized 64x64 condition field. It is unlit and overlays real shadow response. Each local mark is another transparent plane; currentWear combines environment/activity/history/threshold planners. Condition scrub updates existing textures, not absent clean overlays; settled preview rebuilds. Fixture palettes already age by material; object/exposure marks are generic front-facing planes at nominal visual height, even on nonplanar forms. Fixture template/repeated instancing and intact/debris ownership are critical, as are fog concealment, per-cover disclosure, static batches and graphic lighting hooks. No separate wear render target or per-frame CPU scans.

## Implementation checkpoint
W7.1 uses an auxiliary color/alpha mask sampled in the existing lit floor shader, rather than baking a low-resolution copy of the repeating base material. This preserves metric tile/wood seams and avoids a large per-room albedo texture. Atlas UVs map the top face only, with half-texel clamps and no mip bleed; linear filtering and one shared program variant. Initial candidate deliberately retains localized floor marks and fixture decals until their own stages are validated.
