# BP6–9: nine backpack artwork roster
All new models use the BP5R shell facets, shared graphic batch, metric fabric UVs, static material merge and continuous fitted straps. No inventory migration, new item grant, collision or physics. The first four shell builders are unchanged.
- BP6 ALICE medium: 8 x 14 x 15.5 shell, draped lid, three large pockets, exposed simplified frame; Bergen: 10 x 19 x 12.3 central shell plus two rocket pouches (17-unit nominal overall width), top lid, utility pocket. Both have fitted waist ribbons.
- BP7 Medic Assault-style: shallow clamshell, clean angular perimeter graphic, top and side handles, optional neutral medical identification graphic builder parameter. COMM-3-style: narrow rigid access and utility volumes, retention strips and empty cable port; radio and antenna sockets only.
- BP8 school daypack: compact two-volume silhouette and angular zipper. Navy default plus existing curated civilian fabric colors. Rust and slate reuse existing swatches instead of introducing new global color IDs. Civilian preview has a legacy day carrier ID; old sling bag and duffel remain intact.
- BP9 audit all nine using the same material and armor combination; compare body and harness mesh, triangle and vertex counts, validate mount seat and socket bounds. Capture native back, side, rear three-quarter, front, fixed-scale isolated silhouette, mobile game views and five alternate equipment combinations.
