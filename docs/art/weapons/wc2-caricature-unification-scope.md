## Artistic thesis
Toylike, tactile, iconic exterior caricatures: representational, abstracted, authentic, oversized and exaggerated where characteristic. Not uniformly chunky and not literal miniature replicas. Every face earns its place by making the object read more like itself. No inherited benchmark or protected family. Use current evidence, not old approval comments. Scope includes every authored reference and all existing custom visible parts; preview-only status is not changed.

## Review rubric
Use ordinal 0–3 (fails, weak, reads, exceptional) for identity/silhouette, purposeful exaggeration and proportion, sculptural continuity/negative space, authenticity of exterior relationships, consistency of graphic/material vocabulary, economy of visible geometry, and operator-scale read. Mark unknown when no evidence; no artificial numerical pass threshold. Each reference gets a variant-specific photo link, two or more views where available, distinct neighboring game comparison, three most significant identity cues, strongest/current weakness, candidate change, evidence and disposition. Reference image use is exterior visual study only: no internal mechanism, dimensioned drawings, working replicas or manufacturing instructions. Distinguish authentic variant from explicit proxy, and note when only adjacent model images are available.
