# G36 family — reference and campaign coverage checkpoint

## Changes and decisions

- **Bundeswehr Flecktarn, 2000:** G36 original dual-optic service rifle is now the *representative* default. G36K classic dual-optic carbine is a role-specific preview alternative, not asserted routine issue for every infantryman.
- **Bundeswehr Tropentarn, 2010:** same true G36 service default and G36K optional preview. Arid clothing does not itself prove a different rifle or a specific deployment's kit.
- **1997 Bundeswehr historical equipment milestone:** the existing evidence-backed `de-g36` registry identity now maps to the authored G36 service model rather than an AR proxy. The previously recorded 1997 introduction and single-year evidentiary boundary are unchanged. Mapping is *representative*, not an exact certification of the early issued optics/parts or a complete kit.
- **Reference gap dashboards:** `g36-family` now shows the selected modeled family as *approximate/representative* instead of missing. A readable G36 is not documentation of a specific unit's whole rifle setup.
- **2015 generic US tactical-police Dispatch:** G36C is an *optional specialist* preset, **not** the default M4A1, historical issue statement, or blanket patrol/SWAT standard. This is a game armory policy choice. Normal career authorization requires standing 70; configured unrestricted/historical eligibility follows the existing Dispatch setup policies. The 1995 MP5 SWAT look, patrol, OMON, and all other Dispatch options remain unchanged.
- **Operations campaign:** the four factory G36 builds remain available through the existing genuinely owned gameplay rifle/carbine classes and their normal paid weapon procurement and equipment editors. A factory preset does **not** add a free gun, bypass class ownership, manufacture extra ammunition, or imply that an appearance selection purchases a second serialized weapon. No arbitrary G36-only story gate or economics framework is added to modes without an existing per-preset unlock system.
- **Other faction looks:** do not put G36 on French, British, US Army, Russian, generic private-security or unrelated military snapshots without actual narrow evidence. No extra fifth G36 family preset or cosmetic duplicate is introduced.
