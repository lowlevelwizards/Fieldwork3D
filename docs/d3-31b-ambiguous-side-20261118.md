# D3.31B — ambiguous approach-side isolation

An interrupted entry saved from the center plane of a threshold or without approach-side provenance was able to bridge unrelated opposite-side recovery squads. A selected unknown-side actor could recover every same-door incident across both approaches.

Group eligibility now requires **the same immutable recorded side**, with four distinct categories: +1, -1, 0 (physically on-plane), and absent (legacy history). Old histories with absent side can still recover together. No speculative guessing from present position, live locks, unobserved door state or hidden map intel.

When multiple compatible members exist the explicit `RESUME SQUAD` command still validates every actor and authoritatively restores their original nodes in one atomic plan edit; single operator recovery remains independent. New regression tests cover each unknown/legacy combination and ensure a rejected group action leaves snapshots intact.

This is staged behind D3.31A; do not merge until the previous Pages deployment has succeeded and focused checks are green.
