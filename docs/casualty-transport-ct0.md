# CT0 — Transport baseline and release contract
Baseline: 82d0b23 (WR retention merged). Existing drag/carry relies on trailing offsets 25/13, instantaneous movement bearing, bounded body pursuit, separate legacy operator and shared civilian motion paths, and post-pose body lift. A blocked body can reset navigation even if the carrier has a valid route. There is no dedicated paired contact pose.
Release batches: CT-A (0–2), CT-B (3–7), CT-C (8–10), CT-D (11–13), CT-E (14–15). No release while prior production deploy is unfinished. Preserve existing capture/rescue and extraction policy, authored nodes, historical replay defaults. Keep deterministic fixed-step simulation and reuse existing IK; no general physics engine.
Baseline cases: open space, 90/180 turns, narrow passage, partly open leaves, furniture, opposing traffic, stationary teammate, stopped carrier, reverse, friendly/hostile/civilian, pickup/release, interruption, replay, extraction. Existing transport tests are the compatibility floor. Diagnostics measure reciprocal ownership, separation, carrier/body motion and stationary drift. Geometry failures and live visual acceptance remain outstanding until their respective stages.
