# ACH/MICH A1: minimal base shell and single-cover build

Branch: `feature/ach-mich-a1-shell-cover-20261112`. Based on main `7720d8f`.

## Approved scope
- ACH, MICH 2001, MICH 2002 only; do not change PASGT or FAST visual systems.
- Top roof bevel `0.30` game units, applied to both bare shell and fitted fabric.
- ACH brow slightly less projected; ear/nape skirt lifted modestly.
- Bare shell gets four visible retention screws, modest dark rubber edge binding.
- Fixed four-point chinstrap follows basic shell anchors; suppress against bulky facewear.
- One cloth cover: **none/fitted**. Preexisting loose, band, scrim, rail, optical and hardware choices have **no visible effect on these three shells**.
- Separate painted shell solid swatches; selected cover camo never paints shell.
- Curated cover print palette with period-congruent ACH-family and foreign proxies.

## Review gates before any production merge
- Operator Studio WebGL captures: each of three shells, bare and covered, front/side/rear and 3/4, plus small gameplay-scale framing.
- Check fit of rubber binding around intentional ear apertures and nape transitions.
- Check straps do not clip into face, hair, masks, goggles or uniform collar.
- Check camo density on covered shell and absence of bare-shell printed camo.
- Verify old saved customization doesn't revive dormant legacy modules.
- Critical node tests and npm build; no production merge until validation.
