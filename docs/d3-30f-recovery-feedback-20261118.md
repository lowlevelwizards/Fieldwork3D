# D3.30F — actionable, information-safe recovery status

The planning HUD reports ENTRY INTERRUPTED (compact ENTRY HELD) when a witnessed, recoverable door incident remains saved. It does not override unrelated live execution. The existing RESUME ENTRY palette command gains source-aware help text without querying the current door lock state.

The incident is historical, is cleared only by the existing successful player recovery, and never advertises invisible unlocking. No new modal, per-frame world scan, or secondary plan authority. Regression covers pending plans, the compact HUD, coordinated entry, and secret lock-state invariance.
