# SR22 motion cadence regression

Live actor stride is accumulated travel distance (breach-simulation-motion-phase), and Lab supplies clock*40. SR10/SR12 incorrectly multiplied it directly by 2π, yielding dozens of oscillations per second. SR21's amplitude increase exposed that latent bug. All retention weapon, free wrist, and ribbon oscillation consumers now use one fixed 38-art-unit full gait cycle. At ordinary travel speed the motion is roughly 1.4 Hz; second-harmonic bounce roughly 2.8 Hz. No render state or simulation mutation. Settled free arms use the rest pole directly, and the wrist lift is differentiable at zero swing. The existing drop rebound, authored attachment points, and pack layering are unchanged. Added consecutive-frame real rig and distance-rate regression tests. Visual gait synchronization is approximate rather than driven by individual foot contacts.
