# CT13 — Gameplay integration
Execution rejects incompatible loaded hand actions even if authored before acquisition; release is allowed through contact halt, automatic or already-open doors retain compatibility. Firing stops before reload/switch branches during contact/custody, pending defensive footwork cancels. Pickup hit interruption resets its contact timer; treatment and supply recovery require patient set down. Death/surrender/down release reciprocal custody immediately, including legacy orders. Generic extraction archives actual patient and carrier only when both are within the gate, once; dedicated capture/rescue mission rules remain. Legacy drag at gate continues toward the center if the patient has not arrived. No automatic treatment, no resurrection, no new scoring authority. CT14/15 must validate visual and mission-specific edge cases.
