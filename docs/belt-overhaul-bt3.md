# BT3 artwork library

13 carrier-neutral families with stable IDs. Holders have separate contents and contact origins. Artwork is not inventory; BT4–BT6 retain authority over physical issue and transfers. BT7 handles cross-carrier collision. Belt compatibility and footprint data are provisional design values.

## BT3.0 baseline validation
BT0–BT2 head 2a6551a: six PR workflows succeeded; Ground Zero failed only the 45-second 88-operator D3.30 physical arrival gate (non-arrival, locked-door evidence, movement loop). No claim that this is unrelated or pre-existing without a baseline comparison. Preserve this release blocker. Build and focused inventory/visual jobs in that workflow succeeded.

## BT3.1–BT3.7 implementation
All thirteen artwork families and declared variants have a common factory,
separate holder and content nodes, attachment contact origin, content sockets,
interaction socket, shared material channels and per-material mesh batching.
Sample contents are opt-in, and holster fit surrogates are not actual sidearm
geometry. Flap holster and closed medical pouch expose sockets without
visible sample contents. Existing three empty belt accessory styles use the
new factory lazily. No functional equipment is transferred to this library
yet. Operator Lab > Belt Attachment Artwork provides individual auditions,
four role fixtures, variant and full/partial/empty sample choices. This
preview changes only the Lab kit; Undo restores it and OFF hides samples.
Focused tests cover catalog, variants, dimensions, holder persistence and
fixture fit. Gameplay-scale review still requires rendering and human inspection.
