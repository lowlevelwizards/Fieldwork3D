# SR20 — manually authored sling seat pass

All current long-gun receiver/stock/fore-end part IDs now have a dedicated game-art marker or an explicit shared contour choice for finish-only variations. Front marks prefer existing fixed artwork where appropriate; 870 uses the selected tube-cap artwork instead of its pump. Collapsed markers follow the stock transform and folded markers use the receiver. Surface ray projection takes place before rigid compilation, at configuration rebuild only. The review metadata flags missed authored targets for correction rather than conflating a fallback with an accepted art mark.

This is a visual model-coordinate pass, not physical firearm measurements. No sling routing, width, gameplay, weapon geometry, custody or inventory change. Handguns use holsters and have no long-gun sling configuration. Factory screenshots and actual user review remain separate from numerical tests.
