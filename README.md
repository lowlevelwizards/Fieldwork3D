# Fieldwork 3D

A new, mobile-first isometric Three.js interpretation of **Fieldwork**: small teams doing important work in a dangerous, persistent world.

## 0.0.1 — The Diorama

The first milestone is deliberately small: a tactile outdoor scene, a navigable procedural operator, terrain-aware tactical camera controls, and a playable browser build. No legacy AI or combat code has been copied.

Source of truth: this repository's `main` branch. The original `lowlevelwizards/fieldwork` stays intact as an archive/reference.

See the full setup, controls, and architecture notes added with the first implementation.
